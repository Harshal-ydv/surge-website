# SURGE Website

AWS Student Builder Group — JSPM RSCOE

A lightweight, single-file static website for the SURGE AWS workshop. All page styles and JavaScript are embedded in `index.html`; there are no image assets, external dependencies or build steps.

## Deployment options

1. Amazon S3 Static Website Hosting
2. Amazon EC2 + Apache

Upload or copy `index.html` to the hosting root. It also works when opened directly in a browser.

surge-website/
