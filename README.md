# SURGE Website

AWS Student Builder Group — JSPM RSCOE

Static website created for the SURGE AWS workshop.

## Deployment options

1. Amazon S3 Static Website Hosting
2. Amazon EC2 + Apache

Upload or copy the contents of this folder. `index.html` is the entry point; no build step or package installation is required.
